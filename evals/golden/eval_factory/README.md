# Eval Factory Development Canaries

The current immutable development-canary artifacts are:

- `canary_manifest.v4.json`
- `canary_selection_report.v4.md`

They were generated by selector `4.0.0` from 91 locally admitted raw traces. The
24 selected records cover every non-empty source business category and all R0-07
verified-trait and annotation-candidate targets.

Versions without a suffix, `v2`, and `v3` are superseded audit history. Do not
modify or delete them. New selection semantics or source changes require a new
versioned manifest and report rather than overwriting an existing artifact.

The manifest is not annotation truth. Only `verified_traits` count as
deterministic selection evidence; every `annotation_candidates` value requires
R0-08 adjudication.
